# LESS 2027

**1st Workshop on Learning to Extract and Send Semantics (LESS 2027)**

Co-located with the 30th Conference on Innovation in Clouds, Internet and Networks (ICIN 2027), Pisa, Italy — **15 March 2027**.

Workshop site (GitHub Pages): https://borgianni.github.io/less-2027/

## Website

A lightweight multi-page static website, using a shared `styles.css`, with no build system or paid hosting.

- `index.html`: Workshop home and organizers
- `call-for-papers.html`: Official-style technical CFP and mandatory application-based evaluation
- `submission.html`: Paper submission guidance
- `authors.html`: Information for authors
- `program.html`: Workshop program (details forthcoming)
- `committees.html`: Organizing committee
- `contact.html`: Contact information
- `LESS-2027-Call-for-Papers.txt`: Plain-text CFP for mailings and the conference workshop chairs

## Submissions

**Full papers only; maximum 7 pages.** No demo or short-paper tracks.

Submission deadline: **3 January 2027**  
Notification: **18 January 2027**  
Camera-ready: **7 February 2027**

**EDAS submission link:** https://edas.info/newPaper.php?c=35870&track=140815

All papers must be original and unpublished, written in English in the IEEE two-column conference format, with a maximum of seven pages **including all figures, tables, and references**. Accepted and presented papers will be included in the ICIN 2027 conference proceedings. IEEE templates: https://www.ieee.org/conferences/publishing/templates.html
